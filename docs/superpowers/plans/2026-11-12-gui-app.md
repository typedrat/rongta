# Rongta Labels GUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** A desktop app that someone non-technical can use: open a template
file, type an access code, see the exact label, press Print. It also prints
ordinary images.

**Architecture:** A new `rongta-gui` crate (eframe/egui 0.37) in the
`rongta-rs/` workspace. The UI thread never awaits. A `bluetooth` worker thread
owns a current-thread Tokio runtime, runs scans and `rongta_host::job::print`,
and reports back over a channel. Previews reuse the exact raster pipeline
(`Template::raster` / `image_processing::prepare` at 384 dots), so the preview
*is* the print. A custom theme replaces egui's default look: Inter as the UI
font, a warm neutral palette with a teal accent in light and dark variants,
generous spacing, and rounded cards.

**Tech Stack:** Rust 2024, `eframe` 0.37 (wgpu backend), `rfd` 0.18 (native
file dialogs), `image` 0.25, Inter 4.1 (SIL OFL 1.1).

This is Plan B of two and requires Plan A (`2026-11-12-label-templates.md`) to
be merged first. It consumes these interfaces from Plan A:

- `rongta_host::bluetooth::{Address, SystemDiscovery}`. `Address` is `Copy +
  Eq + Display`, and `SystemDiscovery { adapter_name: Option<&str> }`.
- `rongta_host::configuration::Storage`, with `discover(None)`, `effective()`
  and `update(|&mut Settings| -> Result<()>)`. `Settings.printer` has
  `address: Option<Address>` and `media: Option<Media>`.
- `rongta_host::job::{print, Target, Stage}`. On failure while printing, the
  error's outermost context starts with `"Print job failed"`.
- `rongta_template::{Template, Values}` (layout and API as revised after
  Plan A's final review: `size_mm` is the em size, the QR leaves at least 40%
  of the width for text, and `render` can fail on layout problems `check`
  can't see), with `Template::load(&Path)`,
  `.fields` (each with `id`, `label` and `hint`), `.media()`,
  `.normalize(&Values) -> Values`, `.check(&Values) -> Vec<FieldError>` and
  `.raster(&Values, head_width) -> Result<Raster>`.
- `rongta::image_processing::{prepare, preview, Layout}`, plus
  `rongta::monochrome::{Conversion, Dither}` (both `Copy`).

## Global Constraints

- Edition 2024; the workspace keeps `resolver = "3"`.
- Comments explain *why*, for a reader seeing the file cold. No references to
  other modules or to this plan.
- `cargo fmt --all --check`, `cargo clippy --locked --workspace --all-targets
  -- -D warnings` and `cargo test --locked --workspace` pass after every task
  (run from `rongta-rs/` in the dev shell).
- Hard-wrap edited Markdown prose at 80 columns.
- Commit messages use `type: summary`. No attribution trailers.
- Branch `typedrat/gui` stacked on `typedrat/label-templates`.
- The UI thread never blocks on Bluetooth. File dialogs are the one allowed
  blocking call, because that's how native dialogs behave.
- Copy talks to a non-technical person: "Couldn't reach the printer", not
  "RFCOMM connect failed". Raw error chains go only under a collapsed
  "Details".
- macOS and Windows Bluetooth backends haven't been run on hardware. Don't
  claim the app works there until someone has printed from it.

//! follow the system setting.

    self, Color32, CornerRadius, FontData, FontFamily, FontId, Margin, Stroke, Style, TextStyle,
    Theme, Visuals,
    epaint::text::{FontInsert, FontPriority, InsertFontFamily},
    vec2,

static INTER_SEMIBOLD: &[u8] = include_bytes!("../fonts/Inter-SemiBold.ttf");

pub struct Palette {

    pub background: Color32,

    pub surface: Color32,
    /// Buttons and other controls at rest.

pub fn semibold() -> FontFamily {

        "inter",
        FontData::from_static(INTER),

    style.text_styles = [
        (TextStyle::Heading, FontId::new(20.0, semibold())),
        (TextStyle::Body, FontId::proportional(15.0)),
        (TextStyle::Button, FontId::proportional(15.0)),
        (TextStyle::Small, FontId::proportional(12.5)),
        (TextStyle::Monospace, FontId::monospace(13.5)),

    style.spacing.button_padding = vec2(14.0, 7.0);

    visuals.warn_fg_color = p.error;
    visuals.selection.bg_fill = p.accent.gamma_multiply(0.35);
    visuals.selection.stroke = Stroke::new(1.0, p.text);

    widgets.noninteractive.bg_fill = p.surface;
    widgets.noninteractive.weak_bg_fill = p.surface;
    widgets.noninteractive.bg_stroke = Stroke::new(1.0, p.border);
    widgets.noninteractive.fg_stroke = Stroke::new(1.0, p.text);
    widgets.inactive.bg_fill = p.raised;
    widgets.inactive.weak_bg_fill = p.raised;
    widgets.inactive.bg_stroke = Stroke::new(1.0, p.border);
    widgets.inactive.fg_stroke = Stroke::new(1.0, p.text);
    widgets.hovered.bg_fill = p.raised;
    widgets.hovered.weak_bg_fill = p.raised;
    widgets.hovered.bg_stroke = Stroke::new(1.0, p.accent);
    widgets.hovered.fg_stroke = Stroke::new(1.0, p.text);
    // egui grows hovered widgets by default, which makes rows jitter.
    widgets.hovered.expansion = 0.0;
    widgets.active.bg_fill = p.border;
    widgets.active.weak_bg_fill = p.border;
    widgets.active.bg_stroke = Stroke::new(1.5, p.accent);
    widgets.active.fg_stroke = Stroke::new(1.0, p.text);
    widgets.active.expansion = 0.0;
    widgets.open = widgets.active;
    for state in [
        &mut widgets.noninteractive,
        &mut widgets.inactive,
        &mut widgets.hovered,
        &mut widgets.active,
        &mut widgets.open,
    ] {
        state.corner_radius = radius;
    }

    style.visuals = visuals;
    style
}

pub fn palette(ui: &egui::Ui) -> &'static Palette {
    if ui.visuals().dark_mode { &DARK } else { &LIGHT }
}

pub fn card<R>(ui: &mut egui::Ui, add_contents: impl FnOnce(&mut egui::Ui) -> R) -> R {
    let p = palette(ui);
    egui::Frame::new()
        .fill(p.surface)
        .stroke(Stroke::new(1.0, p.border))
        .corner_radius(CornerRadius::same(12))
        .inner_margin(Margin::same(16))
        .show(ui, add_contents)
        .inner
}

pub fn primary_button(ui: &mut egui::Ui, text: &str, enabled: bool) -> egui::Response {
    let p = palette(ui);
    let label = egui::RichText::new(text)
        .font(FontId::new(16.0, semibold()))
        .color(p.on_accent);
    let button = egui::Button::new(label)
        .fill(p.accent)
        .stroke(Stroke::NONE)
        .corner_radius(CornerRadius::same(8))
        .min_size(vec2(140.0, 40.0));
    let response = ui.add_enabled(enabled, button);
    if response.hovered() && enabled {
        ui.painter().rect_filled(
            response.rect,
            CornerRadius::same(8),
            p.accent_hover.gamma_multiply(0.25),
        );
    }
    response.on_hover_cursor(egui::CursorIcon::PointingHand)
}

/// WCAG 2 contrast ratio between two opaque colours.
pub fn contrast(a: Color32, b: Color32) -> f32 {
    fn luminance(c: Color32) -> f32 {
        let channel = |v: u8| {
            let s = f32::from(v) / 255.0;
            if s <= 0.04045 {
                s / 12.92
            } else {
                ((s + 0.055) / 1.055).powf(2.4)
            }
        };
        0.2126 * channel(c.r()) + 0.7152 * channel(c.g()) + 0.0722 * channel(c.b())
    }
    let (x, y) = (luminance(a), luminance(b));
    (x.max(y) + 0.05) / (x.min(y) + 0.05)
}

//! Errors phrased for the person at the printer, with the technical chain
//! kept for anyone helping them.

#[derive(Clone, Debug)]
pub struct Problem {
    pub summary: String,
    pub details: String,
}

impl From<&anyhow::Error> for Problem {
    fn from(error: &anyhow::Error) -> Self {
        let details = format!("{error:#}");
        let summary = if details.starts_with("Print job failed") {
            "The print may not have finished. Check the printer and the label before printing again."
        } else if details.contains("Timed out") && details.contains("connecting") {
            "Couldn't reach the printer. Make sure it's switched on and close by, then try again."
        } else if details.contains("Timed out") {
            "The printer stopped responding. Switch it off and on again, then try again."
        } else if details.contains("BlueZ")
            || details.contains("adapter")
            || details.contains("Winsock")
        {
            "Bluetooth isn't available. Check that it's turned on in your computer's settings."
        } else if details.contains("Pairing failed") {
            "Couldn't pair with the printer. Pair it in your computer's Bluetooth settings, then try again."
        } else {
            "Something went wrong. The details below may help whoever set this up."
        };
        Self {
            summary: summary.to_owned(),
            details,
        }
    }
}
```

//! Bluetooth work on its own thread, so the window keeps drawing while a scan
//! or print takes seconds. Discovery futures aren't `Send`, so the thread runs
//! a current-thread runtime and blocks on one request at a time.
use crate::errors::Problem;
use anyhow::Result;
use eframe::egui;
use image::RgbaImage;
use rongta::{
    bluetooth::{DeviceFilter, ScanDevice},
    image_processing::{self, Layout},
    media::Media,
    monochrome::Conversion,
    printing::PrintOptions,
    raster::Raster,
};
use rongta_host::{
    bluetooth::{Address, SystemDiscovery},
    job::{self, Stage, Target},
};
use rongta_template::{Template, Values};
use std::{
    sync::{Arc, mpsc},
    time::Duration,
};

const SCAN_TIME: Duration = Duration::from_secs(8);
const PRINT_TIMEOUT: Duration = Duration::from_secs(60);

#[derive(Clone)]
pub enum Job {
    Template {
        template: Template,
        values: Values,
    },
    Image {
        source: Arc<RgbaImage>,
        media: Media,
        layout: Layout,
        conversion: Conversion,
    },
}

impl Job {
    pub fn raster(&self, head_width: u32) -> Result<Raster> {
        match self {
            Job::Template { template, values } => template.raster(values, head_width),
            Job::Image {
                source,
                media,
                layout,
                conversion,
            } => image_processing::prepare(source, media, head_width, *layout, None, *conversion),
        }
    }
}

pub struct PrintRequest {
    pub address: Address,
    pub copies: u16,
    pub density: u8,
    pub job: Job,
}

pub enum Request {
    Scan,
    Print(PrintRequest),
}

pub enum Event {
    Scanned(Result<Vec<ScanDevice<Address>>, Problem>),
    Stage(Stage),
    Printed(Result<(), Problem>),
}

pub struct Worker {
    requests: mpsc::Sender<Request>,
    events: mpsc::Receiver<Event>,
}

impl Worker {
    pub fn spawn(ctx: egui::Context) -> Self {
        let (requests, incoming) = mpsc::channel();
        let (outgoing, events) = mpsc::channel();
        std::thread::Builder::new()
            .name("bluetooth".into())
            .spawn(move || {
                let runtime = tokio::runtime::Builder::new_current_thread()
                    .enable_all()
                    .build()
                    .expect("building the Bluetooth runtime");
                let send = |event| {
                    let _ = outgoing.send(event);
                    ctx.request_repaint();
                };
                for request in incoming {
                    match request {
                        Request::Scan => {
                            let result = runtime.block_on(scan());
                            send(Event::Scanned(result.map_err(|e| Problem::from(&e))));
                        }
                        Request::Print(request) => {
                            let result = runtime
                                .block_on(print(request, |stage| send(Event::Stage(stage))));
                            send(Event::Printed(result.map_err(|e| Problem::from(&e))));
                        }
                    }
                }
            })
            .expect("starting the Bluetooth thread");
        Self { requests, events }
    }

    pub fn send(&self, request: Request) {
        // The thread only stops when this sender is dropped.
        let _ = self.requests.send(request);
    }

    pub fn poll(&self) -> Vec<Event> {
        self.events.try_iter().collect()
    }
}

async fn scan() -> Result<Vec<ScanDevice<Address>>> {
    let mut discovery = SystemDiscovery { adapter_name: None };
    rongta::bluetooth::scan(&mut discovery, SCAN_TIME, DeviceFilter::Printers).await
}

async fn print(request: PrintRequest, progress: impl FnMut(Stage)) -> Result<()> {
    job::print(
        Target {
            address: request.address,
            adapter: None,
            pin: None,
            timeout: PRINT_TIMEOUT,
        },
        |info| request.job.raster(info.model.width_dots),
        PrintOptions {
            copies: request.copies,
            density: request.density,
            timeout: PRINT_TIMEOUT,
            ..Default::default()
        },
        progress,
    )
    .await
    .map(|_| ())
}

//! Choosing the printer. The choice is saved where the CLI keeps it, so both
//! tools agree on which printer to use.
use crate::{
    errors::Problem,
    theme,
    worker::{Request, Worker},
};
use eframe::egui;
use rongta::{bluetooth::ScanDevice, media::Media};
use rongta_host::{bluetooth::Address, configuration::Storage};

pub struct Printer {
    storage: Option<Storage>,
    pub selected: Option<Address>,
    pub media: Option<Media>,
    devices: Vec<ScanDevice<Address>>,
    scanning: bool,
    problem: Option<Problem>,
}

impl Printer {
    pub fn load() -> Self {
        let mut printer = Self {
            storage: None,
            selected: None,
            media: None,
            devices: Vec::new(),
            scanning: false,
            problem: None,
        };
        match Storage::discover(None).and_then(|storage| Ok((storage.effective()?, storage))) {
            Ok((settings, storage)) => {
                printer.selected = settings.printer.address;
                printer.media = settings.printer.media;
                printer.storage = Some(storage);
            }
            Err(error) => printer.problem = Some(Problem::from(&error)),
        }
        printer
    }

    pub fn label(device: &ScanDevice<Address>) -> String {
        format!(
            "{} ({})",
            device.name.as_deref().unwrap_or("Unnamed printer"),
            device.address
        )
    }

    pub fn scanned(&mut self, result: Result<Vec<ScanDevice<Address>>, Problem>) {
        self.scanning = false;
        match result {
            Ok(devices) => {
                if self.selected.is_none() && devices.len() == 1 {
                    self.select(devices[0].address);
                }
                self.devices = devices;
                self.problem = None;
            }
            Err(problem) => self.problem = Some(problem),
        }
    }

    fn select(&mut self, address: Address) {
        self.selected = Some(address);
        if let Some(storage) = &self.storage {
            let saved = storage.update(|settings| {
                if settings.printer.address != Some(address) {
                    // Loaded labels belong to the previous printer.
                    settings.printer.media = None;
                }
                settings.printer.address = Some(address);
                Ok(())
            });
            match saved {
                Ok(settings) => self.media = settings.printer.media,
                Err(error) => self.problem = Some(Problem::from(&error)),
            }
        }
    }

    pub fn ui(&mut self, ui: &mut egui::Ui, worker: &Worker) {
        let p = theme::palette(ui);
        ui.horizontal(|ui| {
            ui.label(egui::RichText::new("Printer").font(egui::FontId::new(15.0, theme::semibold())));
            let current = match self.selected {
                Some(address) => self
                    .devices
                    .iter()
                    .find(|d| d.address == address)
                    .map(Self::label)
                    .unwrap_or_else(|| address.to_string()),
                None => "None chosen".to_owned(),
            };
            let mut choice = self.selected;
            egui::ComboBox::from_id_salt("printer")
                .width(280.0)
                .selected_text(current)
                .show_ui(ui, |ui| {
                    if self.devices.is_empty() {
                        ui.label(egui::RichText::new("Press “Find printers” first").color(p.muted));
                    }
                    for device in &self.devices {
                        ui.selectable_value(&mut choice, Some(device.address), Self::label(device));
                    }
                });
            if let Some(address) = choice
                && choice != self.selected
            {
                self.select(address);
            }
            if ui
                .add_enabled(!self.scanning, egui::Button::new("Find printers"))
                .clicked()
            {
                self.scanning = true;
                worker.send(Request::Scan);
            }
            if self.scanning {
                ui.spinner();
                ui.label(egui::RichText::new("Searching…").color(p.muted));
            }
        });
        if let Some(problem) = &self.problem {
            ui.label(egui::RichText::new(&problem.summary).color(p.error));
        }
    }
}

                        density: self.density,

                if self.printer.selected.is_none() {
                    ui.label(
                        egui::RichText::new("Choose a printer first")

                    );
                }
            });
        });

//! The label exactly as it will print: the same raster the printer gets,
//! shown as white paper with black dots whatever the theme.
use crate::theme;
use eframe::egui::{self, Color32, CornerRadius, Margin, Stroke, TextureOptions, vec2};
use rongta::{image_processing, raster::Raster};

#[derive(Default)]
pub struct Preview {
    key: Option<String>,
    texture: Option<egui::TextureHandle>,
    error: Option<String>,
}

impl Preview {
    pub fn clear(&mut self) {
        *self = Self::default();
    }

    /// Renders again only when `key` changes, because rasterizing every frame
    /// would keep a CPU core busy while the window is open.
    pub fn update(
        &mut self,
        ctx: &egui::Context,
        key: String,
        render: impl FnOnce() -> anyhow::Result<Raster>,
    ) {
        if self.key.as_ref() == Some(&key) {
            return;
        }
        self.key = Some(key);
        match render() {
            Ok(raster) => {
                let gray = image_processing::preview(&raster);
                let image = egui::ColorImage::from_gray(
                    [gray.width() as usize, gray.height() as usize],
                    gray.as_raw(),
                );
                // Nearest-neighbour keeps each printer dot a crisp square.
                self.texture = Some(ctx.load_texture("preview", image, TextureOptions::NEAREST));
                self.error = None;
            }
            Err(error) => {
                self.texture = None;
                self.error = Some(format!("{error:#}"));
            }
        }
    }

    pub fn show(&self, ui: &mut egui::Ui, caption: &str) {
        let p = theme::palette(ui);
        theme::card(ui, |ui| {
            ui.label(egui::RichText::new(caption).color(p.muted));
            ui.add_space(4.0);
            match (&self.texture, &self.error) {
                (Some(texture), _) => {
                    let [w, h] = texture.size().map(|v| v as f32);
                    let available = ui.available_width() - 24.0;
                    // Whole-number zoom where it fits, so dots stay even.
                    let scale = if available >= w { (available / w).floor().min(3.0) } else { available / w };
                    ui.vertical_centered(|ui| {
                        egui::Frame::new()
                            .fill(Color32::WHITE)
                            .stroke(Stroke::new(1.0, p.border))
                            .corner_radius(CornerRadius::same(6))
                            .inner_margin(Margin::same(0))
                            .shadow(egui::epaint::Shadow {
                                offset: [0, 2],
                                blur: 8,
                                spread: 0,
                                color: Color32::from_black_alpha(40),
                            })
                            .show(ui, |ui| {
                                ui.add(egui::Image::new(egui::load::SizedTexture::new(
                                    texture.id(),
                                    vec2(w * scale, h * scale),
                                )));
                            });
                    });
                }
                (None, Some(error)) => {
                    ui.label(egui::RichText::new(error).color(p.error));
                }
                (None, None) => {
                    ui.label(egui::RichText::new("Nothing to preview yet").color(p.muted));
                }
            }
        });
    }
}

//! Opening a template, filling in its fields, and previewing the result.
use crate::{preview::Preview, theme, worker::Job};
use eframe::egui;
use rongta_template::{Template, Values};
use std::{collections::BTreeMap, path::PathBuf};

#[derive(Default)]
pub struct TemplateTab {
    template: Option<(PathBuf, Template)>,
    values: Values,
    load_error: Option<String>,
    preview: Preview,
}

impl TemplateTab {
    pub fn open(&mut self, path: PathBuf) {
        match Template::load(&path) {
            Ok(template) => {
                self.values = template
                    .fields
                    .iter()
                    .map(|field| (field.id.clone(), String::new()))
                    .collect();
                self.template = Some((path, template));
                self.load_error = None;
                self.preview.clear();
            }
            Err(error) => self.load_error = Some(format!("{error:#}")),
        }
    }

    /// A job only when the label can actually be drawn: `check` can't see
    /// layout failures such as text too long for its column. Rendering one
    /// small label takes well under a millisecond, so doing it per frame is
    /// fine.
    pub fn job(&self) -> Option<Job> {
        let (_, template) = self.template.as_ref()?;
        let values = template.normalize(&self.values);
        (template.check(&values).is_empty() && template.render(&values).is_ok()).then(|| {
            Job::Template {
                template: template.clone(),
                values,
            }
        })
    }

    /// Errors for fields the person has typed in; blank fields just aren't
    /// ready yet.
    pub fn visible_errors(&self) -> BTreeMap<String, String> {
        let Some((_, template)) = &self.template else {
            return BTreeMap::new();
        };
        let values = template.normalize(&self.values);
        template
            .check(&values)
            .into_iter()
            .filter(|error| values.get(&error.field).is_some_and(|v| !v.is_empty()))
            .map(|error| (error.field, error.message))
            .collect()
    }

    pub fn form_ui(&mut self, ui: &mut egui::Ui) {
        let p = theme::palette(ui);
        let errors = self.visible_errors();
        theme::card(ui, |ui| {
            ui.horizontal(|ui| {
                let title = self
                    .template
                    .as_ref()
                    .map(|(_, t)| t.name.as_str())
                    .unwrap_or("No template open");
                ui.heading(title);
                ui.with_layout(egui::Layout::right_to_left(egui::Align::Center), |ui| {
                    if ui.button("Open…").clicked()
                        && let Some(path) = rfd::FileDialog::new()
                            .add_filter("Label template", &["toml"])
                            .pick_file()
                    {
                        self.open(path);
                    }
                });
            });
            if let Some(error) = &self.load_error {
                ui.label(egui::RichText::new(error).color(p.error));
            }
            let Some((_, template)) = &self.template else {
                ui.label(
                    egui::RichText::new("Open the template file you were sent, or drop it on this window.")
                        .color(p.muted),
                );
                return;
            };
            ui.add_space(4.0);
            for field in &template.fields {
                ui.label(egui::RichText::new(&field.label).font(egui::FontId::new(14.0, theme::semibold())));
                let value = self.values.entry(field.id.clone()).or_default();
                ui.add(
                    egui::TextEdit::singleline(value)
                        .desired_width(f32::INFINITY)
                        .font(egui::FontId::proportional(18.0))
                        .margin(egui::Margin::symmetric(10, 8)),
                );
                match (errors.get(&field.id), &field.hint) {
                    (Some(error), _) => {
                        ui.label(egui::RichText::new(error).small().color(p.error));
                    }
                    (None, Some(hint)) => {
                        ui.label(egui::RichText::new(hint).small().color(p.muted));
                    }
                    (None, None) => {}
                }
                ui.add_space(6.0);
            }
        });
    }

    pub fn preview_ui(&mut self, ui: &mut egui::Ui) {
        let Some((path, template)) = &self.template else {
            self.preview.show(ui, "Preview");
            return;
        };
        let caption = format!("Preview · {} label", template.media());
        let values = template.normalize(&self.values);
        if template.check(&values).is_empty() {
            let key = format!("{}{values:?}", path.display());
            let template = template.clone();
            self.preview.update(ui.ctx(), key, move || template.raster(&values, 384));
        } else {
            self.preview.clear();
        }
        self.preview.show(ui, &caption);
    }
}
```

384 dots is the R22's measured head width. The printed raster is rebuilt
after the handshake using the printer's reported width.

```rust
//! Printing an ordinary picture: choose it, choose how it fills the label and
//! how greys become dots, then preview.
use crate::{preview::Preview, theme, worker::Job};
use anyhow::{Context, Result};
use eframe::egui;
use image::RgbaImage;
use rongta::{
    image_processing::Layout,
    media::Media,
    monochrome::{Conversion, Dither},
};
use std::{path::PathBuf, sync::Arc};

/// (label, dither name); `None` is the SDK's sharp black-and-white threshold.
const STYLES: [(&str, Option<&str>); 4] = [
    ("Sharp — text and logos", None),
    ("Photo — smooth", Some("floyd-steinberg")),
    ("Photo — high contrast", Some("atkinson")),
    ("Pattern", Some("bayer")),
];

#[derive(Default)]
pub struct ImageTab {
    path: Option<PathBuf>,
    source: Option<Arc<RgbaImage>>,
    /// Empty means the printer's saved media.
    media_text: String,
    fit: bool,
    style: usize,
    error: Option<String>,
    preview: Preview,
}

fn load(path: &std::path::Path) -> Result<RgbaImage> {
    let mut reader = image::ImageReader::open(path)
        .with_context(|| format!("Cannot open {}", path.display()))?
        .with_guessed_format()?;
    let mut limits = image::Limits::default();
    limits.max_alloc = Some(64 * 1024 * 1024);
    reader.limits(limits);
    Ok(reader.decode().context("This file isn't a picture this app can read")?.into_rgba8())
}

impl ImageTab {
    pub fn open(&mut self, path: PathBuf) {
        match load(&path) {
            Ok(image) => {
                self.source = Some(Arc::new(image));
                self.path = Some(path);
                self.error = None;
                self.preview.clear();
            }
            Err(error) => self.error = Some(format!("{error:#}")),
        }
    }

    fn media(&self, saved: Option<&Media>) -> Option<Media> {
        if self.media_text.trim().is_empty() {
            saved.cloned()
        } else {
            self.media_text.trim().parse().ok()
        }
    }

    fn conversion(&self) -> Conversion {
        match STYLES[self.style].1 {
            None => Conversion::Threshold(208),
            Some(name) => Conversion::Dither(name.parse::<Dither>().expect("listed dithers parse")),
        }
    }

    pub fn job(&self, saved_media: Option<&Media>) -> Option<Job> {
        Some(Job::Image {
            source: self.source.clone()?,
            media: self.media(saved_media)?,
            layout: if self.fit { Layout::Fit } else { Layout::Label },
            conversion: self.conversion(),
        })
    }

    pub fn form_ui(&mut self, ui: &mut egui::Ui, saved_media: Option<&Media>) {
        let p = theme::palette(ui);
        theme::card(ui, |ui| {
            ui.horizontal(|ui| {
                let title = self
                    .path
                    .as_ref()
                    .and_then(|path| path.file_name())
                    .map(|name| name.to_string_lossy().into_owned())
                    .unwrap_or_else(|| "No picture chosen".into());
                ui.heading(title);
                ui.with_layout(egui::Layout::right_to_left(egui::Align::Center), |ui| {
                    if ui.button("Choose…").clicked()
                        && let Some(path) = rfd::FileDialog::new()
                            .add_filter("Picture", &["png", "jpg", "jpeg", "pnm", "pbm", "pgm", "ppm"])
                            .pick_file()
                    {
                        self.open(path);
                    }
                });
            });
            if let Some(error) = &self.error {
                ui.label(egui::RichText::new(error).color(p.error));
            }

            ui.label(egui::RichText::new("Labels").font(egui::FontId::new(14.0, theme::semibold())));
            let placeholder = saved_media
                .map(|media| format!("{media} (saved)"))
                .unwrap_or_else(|| "e.g. gap:50x30".into());
            ui.add(
                egui::TextEdit::singleline(&mut self.media_text)
                    .hint_text(placeholder)
                    .desired_width(f32::INFINITY),
            );
            if self.media(saved_media).is_none() {
                ui.label(
                    egui::RichText::new("Enter the label size: gap:WIDTHxHEIGHT, circle:DIAMETER, or continuous:WIDTH, in mm")
                        .small()
                        .color(p.error),
                );
            }

            ui.horizontal(|ui| {
                ui.selectable_value(&mut self.fit, false, "Fill the label");
                ui.selectable_value(&mut self.fit, true, "Show the whole picture");
            });
            egui::ComboBox::from_id_salt("style")
                .width(260.0)
                .selected_text(STYLES[self.style].0)
                .show_ui(ui, |ui| {
                    for (index, (label, _)) in STYLES.iter().enumerate() {
                        ui.selectable_value(&mut self.style, index, *label);
                    }
                });
        });
    }

    pub fn preview_ui(&mut self, ui: &mut egui::Ui, saved_media: Option<&Media>) {
        match self.job(saved_media) {
            Some(job) => {
                let key = format!(
                    "{:?}|{}|{}|{}",
                    self.path,
                    self.media_text,
                    self.fit,
                    self.style
                ) + &format!("{saved_media:?}");
                self.preview.update(ui.ctx(), key, move || job.raster(384));
            }
            None => self.preview.clear(),
        }
        let caption = match self.media(saved_media) {
            Some(media) => format!("Preview · {media} label"),
            None => "Preview".into(),
        };
        self.preview.show(ui, &caption);
    }
}
```
